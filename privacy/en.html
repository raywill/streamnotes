StreamNotes Privacy Policy

Effective Date: January 1, 2026

1. Definitions

For the purposes of this Privacy Policy:

  • "StreamNotes" refers to the macOS desktop application formerly known as DailyNotes.
  • "We," "Us," or "Our" refers to the developer and maintainer of StreamNotes.
  • "User" refers to any individual who downloads, installs, or uses the application.
  • "User Data" refers to any content created, stored, or managed locally by the User through StreamNotes.

2. Privacy Principles

StreamNotes is designed in accordance with the following privacy principles:

  • Data Minimization: We do not collect any data that is not strictly necessary.
  • Local-First Architecture: All data remains on the user's local device.
  • No-Server Model: No backend servers store or process User Data.
  • Full User Control: Users have complete ownership and control over their data.

3. Data Collection and Use

3.1 We Do Not Collect Any Personal Data

In the course of using StreamNotes, we do not collect, store, transmit, or process any of the following information:

  • Personally identifiable information (such as name, email address, phone number, etc.)
  • Account or login information (StreamNotes does not have an account system)
  • Note content, tags, titles, file paths, or metadata
  • Device information or unique identifiers
  • Location data
  • Usage behavior, action logs, or analytics data
  • Crash logs or performance diagnostics

4. Local Data Storage and Access

All User Data is stored as standard Markdown (`.md`) files in a user-designated local directory. StreamNotes accesses only the files necessary to provide core functionality and does not access any files or system resources outside the designated directory.

5. Network Communication and Third Parties

  • StreamNotes does not contain any network communication modules and does not initiate network connections during normal operation.
  • StreamNotes does not integrate any third-party SDKs, including but not limited to: advertising services, analytics services, user behavior tracking services.
  • If users choose to sync their local data directory with third-party services (such as iCloud, Dropbox, Google Drive, Git repositories, etc.), that action is entirely user-initiated and governed by the privacy policies of those third-party services.

6. AI, Automation, and External Tools

  • StreamNotes does not provide any AI functionality and does not send User Data to any external AI services.
  • If users process their local data using external tools (such as AI editors, scripts, command-line tools), those actions are entirely user-initiated and controlled.

7. Data Security

Since StreamNotes does not collect, store, or transmit User Data to external servers, there is no risk of data breaches from centralized storage. Users are responsible for securing their own devices and local data.

8. Children’s Privacy

StreamNotes is not designed for children under the age of 13 and does not knowingly collect personal information from children.

9. Changes to This Policy

If future versions of StreamNotes introduce new features involving data processing (such as cloud sync or account systems), we will update this Privacy Policy and publish it on the official website or project repository.

10. Contact

If you have any questions about this Privacy Policy, you can contact us via:

  • The project’s GitHub Issues page
  • The contact information provided on the official website
